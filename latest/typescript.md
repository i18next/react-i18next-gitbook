# TypeScript

{% hint style="warning" %}
Make sure you update to **react-i18next >= 13.0.0** and **i18next >= 23.0.1** and follow the instructions [here](https://www.i18next.com/overview/typescript).
{% endhint %}

{% hint style="info" %}
Examples across these docs come in two tabs: **String keys** (the default, for JavaScript and TypeScript) and **Selector API** (in TypeScript, turned on with [`enableSelector`](https://www.i18next.com/overview/typescript#custom-type-options)).
{% endhint %}
